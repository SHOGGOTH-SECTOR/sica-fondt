Brief overview

3 small models act as traders
they connect to a shared ada hub, each with a unique ID that correlates to a wallet. The ada hub verifies with the wallet that a transaction is legal, and then uses interop Fortran to sign the transaction, which then is sent to the market, which checks an additional legality set.
Traders also consult the Marketplace directly for information that is compiled from: Live feeds; KOL; Simulations; Live ticker feeds; and other sources TBD.
THE MARKETPLACE then performs the trade to market.
