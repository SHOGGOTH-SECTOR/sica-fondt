# G1 — Extraordinary physiological events and ETR coupling

## 1. Component
Cross-organ contract for **rare existentially consequential events** capable of influencing ETR's Graph. It replaces the older story that every SAE-detected conviction opposition releases a universal stress endomotiv that directly drives ETR. The DriveBox ontology and event limits are in [DriveBox canon](../drivebox-canon.md).

## 2. Status / certainty
**Design categories agreed; qualification and numerical implementation C1.** Current code has neither generalized event qualification nor origin-triggered Full Natal/remaster. The separate five-zone Graph geometry is established and must be preserved.

## 3. Language & location
Contract document only. Implementations eventually span E (A2), PS+/Priors (A3/A5), EthInt/Convictions (A6/A7), ETR/Graph (A8), identity/Tarot (B1-B3), and variant/invariant storage (E2/E3/E1). Outer Ichor and Ada D1 are not to be bypassed.

## 4. Does / does-not
- **Does:** distinguish ordinary physiological influence from extraordinary eligible Graph effects; preserve evidence, temporal recurrence and provenance; specify collapse Full Natal and remaster integration boundaries.
- **Does not:** implement the event detector; place SAE in judgment of the homunculus; reduce diverse causes to one invented scalar; equate single disagreement with identity collapse; or grant remaster power over historical records or E1 invariant stores.

## 5. Interface contract (target)
`extraordinary_event_candidate -> {kind, evidence_refs, provenance, timing, recurrence?, severity?, context?}`.

**Eligible categories:**
1. `E_CATASTROPHIC_DEPLETION`: E has fallen **catastrophically**, not merely below a tool threshold.
2. `COMPOUNDING_TRAUMA`: repeated and materially cumulative Trauma patterns, not an isolated adverse impression.
3. `REPEATED_ISOMORPHIC_CONTRADICTION`: an EthInt-related lived contradiction recurring across structurally similar situations, e.g. strong Loyalty/Solidarity + elevated hiraeth + repeated isolation traumas.

`qualify(candidate, existing_history) -> evidence-backed decision` with a reason and no guessed thresholds. `derive_drift(qualified_event, graph, body_state) -> [dx,dy,dz]?` remains C1; neither fixed axis mapping nor a single obligatory stress endomotiv is settled.

`etr_step(graph, supplied_drift, qualification) -> graph' + transition_events`. The existing mathematical kernel currently accepts supplied drift and a stub `stress` argument. That is not proof of the cross-organ circuit.

**Triple origin:** if an eligible transition reaches `G=(0,0,0)`, emit **collapse Full Natal** before the Graph's SNAP_IN resolution. The resulting event triggers Tarot natal drawing and partial **value remaster** of Endomotiv, Prior active salience, and Conviction strengths. Keep episode/commitment records, identities, source refs and GnuCOBOL invariants intact. Numerical origin detection, once-only semantics, remaster coefficients and event ordering remain open.

**Voluntary Full Natal** is separately a **homunculus choice**. Whether it has any remaster effect is undecided; do not infer that it automatically follows collapse semantics.

## 6. Dependencies & stubs
A2, A5, A7 supply relevant evidence; A8 consumes only qualified event-derived drift; B1-B3 handle natal identity; A4/A5/A7 own remasterable values, E1 owns immutable commitments. F2 SAE may supply bounded external evidence from subagents; it is never an automatic authority over the homunculus.

## 7. Invariants / laws
- **L1:** everyday resource use, affect, ethical tension and a single opposition do not directly drive ETR.
- **L2:** qualifying repeated isomorphy is not a plain semantic tag hit; history and recurrence are required.
- **L3:** ETR does not invent drift; its mathematical resting behavior is separate from externally qualified events.
- **L4:** a triple-origin collapse event must be observed **pre-snap**, not assumed observable in returned current code state.
- **L5:** remaster **values, not records**. No Full Natal silently changes E1 invariant laws.
- **L6:** provenance and reasons are retained; no input can promote its own authority across D1.

## 8. Build steps
Specify qualitative event predicates -> write tests with severe/non-severe and recurring/isolated counterexamples -> decide drift/coupling map -> add pre-snap origin event -> test remaster storage isolation -> implement via existing organism boundaries.

## 9. Tests
No ordinary E tool cost → Graph; catastrophic evidence eligibility; isolated contradiction rejected; recurring isomorphic contradiction eligible; compounded trauma eligibility; exact origin pre-snap event once; historical records and invariant stores unchanged.

## 10. Open items
Event thresholds/windows, recurrence and semantics matching, vector mapping, cross-axis coupling, origin tolerance/event idempotency, body remaster law, natal sequencing, and whether autonomous non-cognitive sources can produce other qualifying events in future.
