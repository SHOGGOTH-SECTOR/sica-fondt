# A6 — EthInt: Ethical Integrity

## 1. Component
EthInt belongs inside **E**. It reads the memory-derived **Conviction array (A7)** and both (a) signals the homunculus directly and (b) modifies literal **E tool costs**. It is character/history exerting pressure, not a moral oracle, a court, or an action permitter.

## 2. Status / certainty
**Design clarified; code stale.** `driver_ethical_integrity.R` uses manually seeded principles and exponential constants from the disowned four-driver approval path. The numbers and data provenance are not validated by current design.

## 3. Language & location
R `core/src/endocrine/driver_ethical_integrity.R`; conviction storage/derivation A7. Interface into Ada and E A2 remains to implement.

## 4. Does / does-not
- **Does:** expose ranked convictions with strengths and situational arguments; price alignment, antithesis, and compromise for the specific tool/trajectory; update lived conviction values from chosen actions and retained memories; supply evidence of **repeated isomorphic contradictions** for exceptional Graph drift qualification.
- **Does not:** accept or reject a homunculus action, override invariants, judge cognition, treat a single opposition as existential collapse, or write its changing values into GnuCOBOL self-binding stores.

## 5. Interface contract (target)
- `top_convictions(array, x) -> ordered convictions` (adaptive X, approximately seven currently illustrative).
- `signal_ethint(context) -> attributed conviction posture` independent of pricing.
- `price_ethint(tool, trajectory, convictions, context) -> cost_modifier`; stronger antithesis may impose greater cost and alignment may discount cost; compromise is a real separate trajectory. **No inherited exponential k values.**
- `record_choice_and_retention(outcome, memory_refs) -> next conviction values` distinct from tool availability decision.
- `isomorphic_contradiction_evidence(sequence) -> candidate` captures recurring mismatch between convictions and lived history; whether eligible for ETR remains separately assessed.

## 6. Dependencies & stubs
A7 conviction array, E A2 for pricing, memory E2/E3 for derivation, A1 for signals, extraordinary Graph event classification A8/G1.

## 7. Invariants / laws
- **L1:** dual path to cognition and E costs. Neither path is an independent approval gate.
- **L2:** convictions arise through history; strength can change, including via collapse remaster, while underlying memory records remain.
- **L3:** opposing commitments may be lived simultaneously; an intermediate response is its own option, not an automatically superior compromise.
- **L4:** repeated isomorphic contradiction may affect ETR. A solitary output mismatch or SAE alert does not.
- **L5:** convictions are mutable character; GnuCOBOL invariant commitments have a different authority and lifecycle.
